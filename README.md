# dashboard-vendas-excel
Estudo de causa de vendas 
Dashboard de Vendas — Excel
Objetivo
Este projeto organiza dados de vendas e transforma registros tabulares em indicadores e gráficos que facilitam a análise do desempenho comercial.
Arquivos
Dashboard_Vendas_DIO.xlsx: arquivo Excel com dashboard, base de dados e instruções.
README_Dashboard_Vendas.md: documentação do projeto.
Dados utilizados
A planilha contém 240 registros fictícios de vendas, distribuídos entre janeiro e outubro de 2026. Os dados são demonstrativos, criados para fins educacionais e não representam transações reais.
Campos principais: ID da venda, data, região, vendedor, categoria, produto, quantidade, preço unitário, faturamento e forma de pagamento.
O que o dashboard apresenta
Faturamento total;
Unidades vendidas;
Número de vendas;
Ticket médio;
Faturamento mensal;
Participação por categoria;
Faturamento por região.
Como reproduzir
Baixe Dashboard_Vendas_DIO.xlsx deste repositório.
Abra o arquivo no Microsoft Excel ou em aplicativo compatível.
Acesse a aba Dashboard para visualizar os indicadores e gráficos.
Consulte Base de Dados para verificar os registros.
Para testar atualizações, acrescente vendas mantendo as colunas existentes e confira os intervalos das fórmulas e dos gráficos.
Recursos utilizados
Tabelas e filtros do Excel;
Fórmulas SUM, COUNTA, IFERROR, SUMIFS e SUMIF;
Gráficos de coluna, pizza e linha;
Formatação condicional/visual e organização por abas.
Observação
Os dados são fictícios e o projeto tem finalidade didática. O dashboard foi estruturado para demonstrar organização, visualização e análise de dados de vendas.
